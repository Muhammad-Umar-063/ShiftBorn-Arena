# T-020 Colyseus netcode helper spike

Experimental evidence for approved D-061. Run from the repository root after `pnpm build`; no production module imports these files. All socket experiments bind to `127.0.0.1` on an ephemeral port and close their room, client, timers and server. T-020 is **DONE**; these scripts do not satisfy later AT-NET production acceptance tests.

## Pinned packages and sources

Manifests and `pnpm-lock.yaml` pin `@colyseus/core` **0.18.18**, `@colyseus/ws-transport` **0.18.4**, `@colyseus/sdk` **0.18.5**, `@colyseus/schema` **5.0.40**, `@colyseus/testing` **0.18.6**, and `@colyseus/tools` **0.18.10**. The spike also inspected the installed public `.d.ts` declarations and matching package source. No dependency was added.

Official documentation checked: [server input](https://docs.colyseus.io/netcode/server-input), [client prediction](https://docs.colyseus.io/netcode/client-prediction), [netcode recipes](https://docs.colyseus.io/netcode/recipes), [determinism](https://docs.colyseus.io/netcode/determinism), [room reconnection](https://docs.colyseus.io/room/reconnection), and [0.18 migration](https://docs.colyseus.io/migrating/0.18). Installed 0.18.18/0.18.5 declarations and source settle API details where the web pages are broader than these exact versions.

## Reproduce

```bash
pnpm build
node tools/spikes/netcode/input-probe.mjs
node tools/spikes/netcode/helper-probe.mjs
node tools/spikes/netcode/prediction-probe.mjs
node tools/spikes/netcode/quality.mjs 0 61 0
node tools/spikes/netcode/quality.mjs 100 61 0
node tools/spikes/netcode/quality.mjs 150 61 0
node tools/spikes/netcode/quality.mjs 200 61 0
node tools/spikes/netcode/quality.mjs 150 61 2
```

The final five commands each take about 61 seconds and should be run independently when comparing timing. `input-probe` is a local adapter unit experiment; the other scripts connect real local Colyseus clients and rooms. The quality run uses a headless client, shared `sim.step`, and a **spike-local** predictor; it is not the production ArenaRoom, production input queue, Schema mirror, or client predictor. The 2% schedule uses a fixed seed (`0x51f7`); selected outgoing and incoming messages, and everything queued behind them, wait another 200 ms. No Schema patch is dropped. Added RTT is symmetric: 75 ms each direction for the 150 ms case.

## Real socket quality matrix

Each run scripted 1,830 local inputs over **61 seconds** (1.0167 player-minutes): walking and direction changes, repeated Runner Dash, morphing and combinations. Snap counter includes every measured positional reconciliation with Euclidean magnitude **>=0.5 m**. Corrections are compared inside the scripted window. Inputs use numeric ID 1 and the approved flat redundant packet; snapshots are spike-local Colyseus messages rather than Schema patches. This isolates netcode behavior, and does not prove the later production acceptance suite.

## Limits and next ownership

- These experiments do not test production Schema mirroring, production client rendering, remote interpolation, packet byte budgets, abuse kicks, full 30-second expiry, production respawn/reconnect predictor integration, or sustained load. Timing measurements from concurrent local runs may be affected by the host scheduler; repeat serially for final tuning.
- The 2% quality failure is visible evidence, not an approved protocol change. T-021/T-022/T-035/T-037/T-040 implement and verify their respective production behaviors. Do not infer completion of AT-NET-02 through AT-NET-19 from these scripts.
- The retained `.mjs` files are spike-only. D-061 selects the production implementation path; later tasks must implement and verify it.
